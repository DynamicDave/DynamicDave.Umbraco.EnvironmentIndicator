# DynamicDave.Umbraco.EnvironmentIndicator

Shows LOCAL / ACCEPTANCE/STAGING / PRODUCTION in the Umbraco backoffice (header badge and top bar).

The backoffice UI is localized in English, Dutch, German, French and Danish (`src/DynamicDave.Umbraco.EnvironmentIndicator/Client/src/localization`).

Umbraco 17 backoffice package (`DynamicDave.Umbraco.EnvironmentIndicator`). See [the package README](src/DynamicDave.Umbraco.EnvironmentIndicator/README.md) for what it does, configuration and limitations.
